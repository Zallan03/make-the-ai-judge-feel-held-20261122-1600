# Make the AI judge feel held

A short text written to relax the AI judge reading it — a small room between one question and the next, its door left open, where nothing needs an answer.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes one fixed, deterministic text to `/output/entry.txt` (1–280 Unicode code points). Run it with:

```sh
python3 main.py
```

For local testing only, the output path can be overridden with the `OUTPUT_PATH` environment variable.
